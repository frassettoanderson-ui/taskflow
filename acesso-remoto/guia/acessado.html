Acesso remoto: instalar neste computador

Para o suporte conseguir acessar este computador quando você precisar.

Windows

  1. Abra o navegador e entre em holytechsolution.com.br/remoto. O download começa sozinho.
  2. Abra o arquivo baixado (HolyTech-Remoto-Setup.exe).
    • Se aparecer "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo.
  3. Crie uma senha de pelo menos 8 caracteres e repita.
  4. Avance até o fim. A última tela mostra o ID deste computador.
  5. Envie o ID e a senha para o suporte.
Pronto. O programa liga sozinho junto com o computador. Você não precisa abrir nada nem aceitar o acesso.

Mac

  1. Baixe o RustDesk em rustdesk.com (versão macOS) e arraste para a pasta Aplicativos.
  2. Abra o RustDesk, vá em Configurações → Rede → Servidor de ID/Relay e preencha:
    Servidor de ID
    178.238.226.21
    Chave
    RO+BSgUSgcTp5rY1AY62i+3jptBiYajH5B8GCiMMj64=
  3. Em Ajustes do Sistema → Privacidade e Segurança, marque o RustDesk em Gravação de Tela, Acessibilidade e Monitoramento de Entrada. Depois feche e abra o RustDesk.
  4. Em Configurações → Segurança, crie uma senha permanente.
  5. Envie o ID (aparece na tela inicial) e a senha para o suporte.

Dúvidas

Posso desligar o computador?Pode. Quando ligar de novo, o acesso volta sozinho.
Alguém pode entrar sem eu saber?Só quem tem o ID e a senha. Passe os dois apenas para o suporte.
